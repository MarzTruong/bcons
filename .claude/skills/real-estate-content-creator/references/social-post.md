# Social posts (Facebook, Zalo, Threads)

## Platform constraints (they change how you format)
- **Facebook** (personal profile / fanpage): renders no markdown. No `|` tables, no `**bold**`, no `#` headers. Use line breaks, short paragraphs, "✅"/"•"/"–" bullets, and "→" for flows. First 2 lines show before "Xem thêm", so the hook must land there. Length: 150-400 words for analysis, 80-150 for a listing.
- **Zalo** (personal/group/OA post): shorter than Facebook, 80-200 words; same plain-text formatting. Lead with the most useful number. Count the words before saving; if it runs over, keep the honest trade-off and cut detail instead (e.g. move the full payment schedule into a follow-up message the user sends when someone replies).
- **Threads**: 500 characters per post. Write a thread of 3-6 numbered posts (1/5, 2/5…), each standing on its own. Contact line in the last post.

## Post types

1. **Phân tích tài chính** ("cầm 400 triệu mua căn…", "thuê hay mua", "PTTT nào hợp với ai"): persona → the question → step-by-step cash flow with loan_calc.py numbers → trade-offs → who this fits / who should wait → CTA.
2. **Storytelling**: a realistic buyer situation (say it's an example unless the user gives a real, consented story), the decision they faced, what the numbers showed. No invented testimonials presented as real.
3. **Listing (tin bán căn)**: căn/loại căn, diện tích, tầng/hướng/view (only if in the data), giá chưa VAT + PTTT, tiền cần chuẩn bị theo đợt, 1-2 honest notes, CTA. Only units that are currently on sale — not CĐT LOCK, not đã cọc; ask the user to confirm status if the price file is old.
4. **Tiến độ / thị trường**: what changed (with date + source or the user's own photo/visit), what it means for a buyer, what's still uncertain.

## Layout template (Facebook / Zalo)

```
<Hook: 1-2 lines, a specific question or number>

<Context: 1-3 short lines — who this is for>

<Section label, e.g. "Tính thử căn 2PN 50m² theo phương thức số 4:">
– Giá: … tỷ (chưa VAT, chưa 2% phí bảo trì)
– Tiền tự có đến lúc ký HĐMB: … triệu
– Khoản vay: … tỷ → giai đoạn CĐT hỗ trợ lãi: …
– Sau hỗ trợ, lãi … %/năm (giả định), vay … năm (giả định) → tháng đầu khoảng … triệu
– Chi phí khác: phí quản lý …, giữ xe …

Điểm em thấy ổn:
✅ …
Điểm anh chị cần cân nhắc:
– …

<Takeaway: who this fits, who should wait>

<CTA line>
Tuấn - 0938.32.31.39

<small print: Thông tin tham khảo theo chính sách CĐT ngày …; số liệu thị trường theo <nguồn, ngày>; các mục ghi (giả định) là ví dụ tính toán.>
#BconsCentralPark #CănHộBiênHòa …
```

Keep 3-6 hashtags, relevant ones only.

## Rent vs buy / rental yield
Never state a rent figure without a source (a listing site page + date, or the user's own data). Without it: `[Cần bổ sung: giá thuê thực tế căn <loại> khu <khu vực>, nguồn + ngày]`, and still show the structure of the comparison so the user just fills the number. Gross yield = annual rent ÷ total cost (price + VAT + bảo trì) — say "gộp, chưa trừ phí quản lý, thời gian trống".
